# Liga Inmortales

Web de la liga fantasy LIGA INMORTALES (temporada 2026-27).

- `index.html`: la página (se genera con `build.py` en el proyecto; no editar a mano).
- `config.js`: configuración pública de Firebase.
- `firestore.rules`: reglas de seguridad de Firestore (copiar en la consola de Firebase).
- `betfire/index.html`: BetFire 🔥, la porra de apuestas entre amigos y la ruleta. Usa el mismo proyecto de Firebase (colección `betfire_members`).
